# USB-Blaster II enclosure — v2

Four printed parts, no hardware. Everything is generated by `cradle_cq.py`
(CadQuery 2.8); edit the parameter block at the top and re-run to regenerate
all twelve export files.

```
pip install cadquery
python cradle_cq.py      # writes out/*.step, out/*.stl, out/*.3mf
python verify.py         # clearance + interference + overhang report
```

## What changed from v1

| | v1 | v2 |
|---|---|---|
| USB opening | fixed window in the end wall | 16 × 14.5 mm slot running from low in the shell up **through the parting line**, so it cannot miss the receptacle whatever height it sits at |
| Plug boot | tight | end wall thinned to 1.2 mm over a 22 mm recess so a moulded boot seats inside the shell |
| Closure | cantilever clips | same idea, re-cut so the catch face is a printable 37° overhang and the window's top edge lands **on** the catch — 0.2 mm of lift play instead of 1.3 mm |
| Strain relief | clamp against the end wall | flat tail that reaches **past** the plug boot, then a ribbed saddle + cap + 2 thumb screws |
| Printability | supports needed | shell 0.6% overhang, cover 0.0%, cap 0.0% — nothing needs support |

## Printing

Meshes are exported **already oriented for the bed** — drop the STL or 3MF
straight into the slicer, no rotation. (The STEP files stay in assembly
coordinates so you can open the whole thing together in CAD.)

| Part | Orientation | Notes |
|---|---|---|
| `shell` | as exported, floor down | four 10 mm bridges over the clip windows, no support |
| `cover` | as exported, lid down | clips point up, prints clean |
| `clamp_cap` | as exported, flat face down | groove faces up |
| `screws_x2` | as exported, heads down | thread flanks self-support |

PETG, 0.2 mm layers, 4 perimeters, 25–30% infill. The clip arms are 1.9 mm
thick — 4 perimeters means they print solid, which is what you want for a
spring. Print `screws_x2` at 0.12–0.15 mm for a cleaner thread; the pilot
cores in the shell are plain 2.7 mm holes and the screws cut their own
thread on first use, so run them in slowly the first time.

PLA works but the clips get brittle. ABS/ASA if it lives somewhere warm.

## Assembly

1. Drop the pod into the shell, USB receptacle facing the big opening.
2. Feed the ribbon out through the tunnel at the far end.
3. Press the cover straight down until all four clips click.
4. Plug the USB cable in, lay the cable in the saddle groove, put the cap on
   and run the two thumb screws down until the ribs bite the jacket. Don't
   crush it — snug is enough, the ribs do the work.

**To open it:** push a paperclip into any clip window, press the barb inward
about 1 mm, and lift that corner. There's a fingernail scallop mid-way along
each long side. Two people-hands is easiest: release the two clips on one
side, then rock the cover off.

## Things to measure and change

Everything below lives in the parameter block at the top of `cradle_cq.py`.

- **`CABLE_D = 4.0`** — the USB cable jacket. This is the one number I had to
  guess. Measure yours with calipers; the bore is `CABLE_D + 0.2` and the
  grip ribs pinch 0.9 mm under that.
- **`USB_PRESET = "typeB"`** — the genuine PL-USB2-BLASTER carries a standard
  USB Type-B receptacle. Clones sometimes use mini-B or micro-B; switch to
  `"miniB"` or `"microB"` for a tidier opening.
- **`USB_BOOT_L = 22.0`** — how far your plug's moulded boot sticks out past
  the end wall. The tail length is checked against this at run time; if your
  cable has a short boot you can cut `SR_TAIL_L` down and save 10 mm of
  footprint.
- **`DEV_L / DEV_W / DEV_H`** — datasheet numbers (63.5 × 41.4 × 20.6). If you
  calliper the actual pod and it differs, change these three and re-run;
  everything else follows.
- **`CLR_XY = 0.6`, `CLR_Z = 0.5`** — deliberately loose. If the pod rattles,
  drop to 0.4 / 0.3.
- **Clips too tight or too loose:** `BARB` (1.8) sets both the holding force
  and the release travel. `ARM_T` (1.9) sets the spring rate — thinner is
  softer. `BARB_CATCH` (2.4) trades holding force against print quality;
  smaller is a steeper catch and a worse overhang.
- **`RIB_W / RIB_H`** (16 × 3.6) — the ribbon tunnel. A 10-way 1.27 mm ribbon
  is 12.7 mm wide, so there's room; tighten if you want it snug.
